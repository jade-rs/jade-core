# Inline picture positions in table cells

Microsoft Word for Mac exported these synthetic documents to PDF. The
coordinate fixtures cover three cases.

- `positioned-inline-pictures-mac` combines raised and lowered pictures with
  Japanese and Latin text, rotation, and East Asian automatic spacing.
- `table-picture-baseline-matrix-mac` covers 24 combinations of image size,
  rotation, and text with the default picture position.
- `table-picture-position-matrix-mac` covers 24 combinations of image size,
  rotation, and 4 pt offsets above and below the baseline. Each case has a
  following paragraph whose position also depends on the preceding line height.
