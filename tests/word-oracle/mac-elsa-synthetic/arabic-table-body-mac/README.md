# Arabic shaping in table cells and body text

The synthetic DOCX covers Arabic in left-to-right and right-to-left
paragraphs, mixed Latin and Arabic, two explicit runs, vowel marks, and
font changes. The final paragraph places Arabic after a Latin prefix
outside the table.

The reference records text origins from the one-page Word for Mac PDF.
Each page records its shaped Arabic spans as text, leftmost origin, and
baseline in points. The browser check compares those spans on the same page. It compares the other visible text at the
individual glyph origins. The per-axis tolerance is 0.65 pt.
