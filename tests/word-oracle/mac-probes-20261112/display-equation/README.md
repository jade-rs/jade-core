# Word for Mac display equation probes

These 16 synthetic sources are ready for Word measurement. Word coordinates
and CI assertions are pending.

- Alignment and RTL wrap vary paragraph direction, justification and
  document-level math display defaults.
- Fraction line boxes compare three font sizes, fraction variants and equations
  inside and outside tables.
- The italic Latin documents separate lowercase and uppercase math spacing
  and wrapping.
- Manual breaks cover alignment points on forced continuation lines.
- Automatic operator breaks vary the `m:brkBin` mode and the position of the
  relation operators in an otherwise identical equation.
- Paragraph indents, table cell widths and unequal page columns vary the width
  available for display equations.

Export each source from Word for Mac with Save As PDF, Best for printing.
Compare page size, equation wrapping and each visible glyph origin. Include
the paragraphs following the equations in the comparison so that line box
height regressions are detected.
