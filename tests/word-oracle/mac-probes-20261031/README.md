# Word for Mac superscript and subscript sweep

`word-mac-probe-vert-align-sweep.json` was captured by Word for Mac 16.114.3
(build 16.114.26102720) on macOS 27.0.1 from the unchanged
`public/fixtures/word-mac-probe-vert-align-sweep.docx`, generated by
`generators/make-vert-align-sweep-probe.py`. Word saved it as PDF through
AppleScript (`save as … file format format PDF`) with no edits. The DOCX and
PDF SHA-256 are in the JSON; the PDF remains at the capture workstation as
`~/Downloads/Jade-Word-Probes-20261031/word-mac-probe-vert-align-sweep.pdf`.

Each paragraph is `A12B` with `12` superscript or subscript: Yu Mincho,
Century, MS Mincho and Calibri, 6 to 30pt by half points, 392 paragraphs.
`generators/extract-vert-align-sweep.py` reads the run sizes and baselines
from the PDF's text matrices, which Word writes in 1/300in (0.24pt) device
units, so no glyph boxes or descent shares are involved.

What it shows:

- Every script size is the face's OS/2 superscript size (1331/2048 in
  Century and Calibri, 0.6 in Yu Mincho and MS Mincho) to the nearest half
  point. A flat 0.65 rounds 15 and 25pt up to 10 and 16.5pt; Word draws 9.5
  and 16pt.
- Every move is a whole number of half points. Century and Yu Mincho, above
  and below, are the face's OS/2 offset times the size to the nearest half
  point, halves up, at all 49 sizes; MS Mincho's superscript is 0.4 of the
  size the same way.
- Calibri (both ways) and MS Mincho's subscript are clamped below their
  OS/2 offsets, and not by any rule of the run and script sizes: no linear
  or two-stage rounded form in half points, twips or device units fits all
  49 sizes, and 13pt Calibri moves up 4pt while 12.5pt moves 4.5pt. Jade
  keeps these 147 moves as a table and falls back to its shares (Calibri
  0.333 and 0.094, MS Mincho 0.11) outside 6–30pt.

same day, from `public/fixtures/word-mac-probe-vert-align-sweep-2.docx`
(`generators/make-vert-align-sweep-2-probe.py`); its PDF is kept beside the
first. It repeats the clamped paragraphs with Calibri's East Asian font set
to Calibri, Yu Mincho and MS Mincho, with `xx` raised in place of `12`, and

depends on neither the East Asian font nor the glyphs.

run's alignment, faces, size and text from the DOCX.
