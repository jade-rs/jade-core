# Pivot/cache regression fixture

Original deterministic test data generated by
`scripts/xlsx/generate_pivot_fixture.py`; no reference-implementation or third-party
workbook content is included. Source/cache values are East 10+5 and West 20+7,
with the saved report holding 15, 27 and 42. A historical shared item at index1
is unused but retained so West's record index2 cannot silently shift. Dates
remain ISO cache items and source numeric 1900-epoch values.

The fixture includes declared workbook/cache/record/table relationships and
content types. It is a generated regression input, not an Excel save/repair,
rendering or full schema-validation oracle. Repeated/grouped axes, refresh,
calculated/OLAP fields and more complex producer files need separate evidence.
