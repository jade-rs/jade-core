# Decks from Apache POI

These `.pptx` files are copied unchanged from Apache POI's test data,
`test-data/slideshow/` at commit `bf7c9b6a1490046517cbd8e1504e702a89be4bc9`
(<https://github.com/apache/poi/tree/bf7c9b6a1490046517cbd8e1504e702a89be4bc9/test-data/slideshow>).

Apache POI is licensed under the Apache License, Version 2.0
(<https://www.apache.org/licenses/LICENSE-2.0>). The files are real decks —
saved by PowerPoint, by LibreOffice, and taken from published presentations —
with tables, charts, SmartArt, embedded video and audio, themes, layouts and
custom geometry, which the PowerPoint round-trip tests open, edit and save.
